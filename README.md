# Aryan Patel | Portfolio

A responsive Next.js portfolio built with TypeScript, custom CSS and Framer Motion.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Visit http://localhost:3000

## Deploy on Vercel

1. Create a GitHub repository, for example `aryan-portfolio`.
2. Push this folder to that repository.
3. Sign in at https://vercel.com with GitHub.
4. Select **Add New → Project**, import `aryan-portfolio`.
5. Keep the default Next.js settings and click **Deploy**.
6. Vercel will provide your public portfolio URL.

## Before publishing

- Check all project details and repository links.
- Check the LinkedIn URL.
- Add a resume PDF to `public/` and add a download link if you want one.
- Confirm that all claims and metrics are still accurate.
- Update the metadata and contact details if needed.
